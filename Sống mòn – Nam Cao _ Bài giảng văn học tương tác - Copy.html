📑 Mục Lục Bài Học
    Đã cập nhật văn bản & đồng bộ vào JSON!

    📥 Import Chủ Đề & Dữ Liệu Bài Giảng

    Sẵn sàng tạo prompt, dán JSON hoặc nạp từ file HTML đã lưu.

    ⌨️ Hướng Dẫn Phím Tắt Trình Chiếu

    • → hoặc Space : Hiện từng câu / từng phần tiếp theo (và đọc nếu bật cần gạt)
    • ← : Lùi 1 bước (hoặc chuyển ảnh khi đang phóng to ảnh)
    • + / - : Tăng / giảm cỡ chữ (tối thiểu 1.5rem)
    • T : Chuyển đổi màu nền (Giấy cổ điển / Xanh dịu / Tối)
    • H : Ẩn / hiện thanh công cụ phía trên
    • G : Mở / đóng bảng hướng dẫn phím tắt
    • U : Mở / đóng lịch sử cập nhật ứng dụng
    • Esc : Đóng phóng to ảnh, mục lục, modal import, lịch sử cập nhật hoặc hướng dẫn

    📜 Lịch Sử Cập Nhật Ứng Dụng

    Phiên bản 2.5 • Mới nhất
    • Thêm nút 📂 Import từ file trong modal Import cho phép chọn file .html đã lưu (hoặc .json) để tự động trích xuất dữ liệu JSON và hiển thị ngay lên trang.
    • Cân đối lại giao diện hàng nhập chủ đề và ô Số ảnh tham khảo trong modal Import cho đồng đều chiều cao và tỷ lệ.
    Phiên bản 2.4
    • Mở rộng chiều cao khung ảnh phần Tiêu điểm khám phá & Ghi chú minh họa (#sec-spotlight) theo tỉ lệ vuông 1:1 (360px × 360px) giúp hình ảnh cân đối, rõ nét hơn.
    • Sửa lỗi kích hoạt Lightbox nhầm khi nhấp hoặc bôi đen văn bản trong các thẻ Tiêu điểm: chỉ mở phóng to ảnh khi nhấp trực tiếp vào ảnh.
    • Chuyển bố cục phần Tiêu điểm khám phá xuống dưới phần Trích đoạn tiêu biểu & Thế giới đồng thoại, đồng thời bổ sung thanh banner tiêu đề cho phần Trích đoạn.
    • Thêm nút U trên thanh công cụ (và phím tắt U) để tra cứu lịch sử cập nhật.
    Phiên bản 2.3
    • Bổ sung chế độ Edit URL cho phép sửa trực tiếp đường dẫn ảnh, khôi phục ảnh gốc hoặc bấm nút ✕ xóa nhanh từng ảnh và đồng bộ vào JSON.
    • Thêm tùy chọn Hiện ảnh trước để hiển thị toàn bộ hình ảnh minh họa ngay từ đầu buổi học.
    Phiên bản 2.2
    • Tích hợp tính năng Import JSON & Copy Prompt tùy chỉnh số lượng ảnh tư liệu từ AI.
    • Hỗ trợ Lưu file HTML độc lập chứa trọn nội dung đã biên soạn và tự động khóa chỉnh sửa khi trình chiếu.
