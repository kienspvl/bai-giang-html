Phần 1

Kiểu bộ chọn Pseudo-class và Pseudo-element

Tìm hiểu các trạng thái đặc biệt của phần tử HTML và cách chọn lọc các thành phần con một cách tinh tế.

1a

Bộ chọn Pseudo-class (Lớp giả)

Ký hiệu bằng dấu đơn :pseudo-class chỉ trạng thái đặc biệt.

#PseudoClass ↗ #HoverLink ↗

Pseudo-class (lớp giả) là khái niệm chỉ các trạng thái đặc biệt của phần tử HTML. Các trạng thái này không cần định nghĩa mà mặc định được coi như các lớp có sẵn của CSS. Cú pháp: :pseudo-class { thuộc tính: giá trị; }

Bộ chọn Ý nghĩa Ví dụ minh họa
:link Tất cả các liên kết khi chưa được kích hoạt. a:link { color: blue; }
:visited Tất cả các liên kết sau khi đã kích hoạt một lần. a:visited { color: gray; }
:hover Tất cả các phần tử khi con trỏ chuột di chuyển lên. #home:hover { font-size: 150%; }
💡 Xem thẻ chi tiết & Mẹo ghi nhớ Pseudo-class
Bấm để mở ↗
1b

Bộ chọn kiểu Pseudo-element (Phần tử giả)

Ký hiệu bằng dấu kép ::pseudo-element chỉ định dạng một phần nhỏ của phần tử.

#PseudoElement ↗ #FirstLetter ↗

Pseudo-element (phần tử giả) chỉ một phần (hoặc một thành phần) của các phần tử bình thường, có thể thiết lập định dạng CSS độc lập. Quy định viết sau dấu đôi ::.

Bộ chọn Mô tả Ví dụ
::first-line Dòng đầu tiên của đối tượng văn bản. p.test::first-line { font-family: monospace; }
::first-letter Kí tự đầu tiên của đối tượng văn bản. #first::first-letter { font-size: 200%; }
::selection Phần văn bản được người dùng bôi đen (chọn) trên màn hình. ::selection { background-color: lime; }
Phần 2

Mức độ ưu tiên và Trọng số CSS (Specificity)

Khi có nhiều quy tắc CSS cùng tác động lên một phần tử, trình duyệt sẽ tuân theo các cấp bậc ưu tiên nghiêm ngặt.

7

7 Mức độ ưu tiên CSS (Từ cao xuống thấp)

Số thứ tự ưu tiên lớn hơn sẽ ghi đè lên số nhỏ hơn.

STT Loại CSS / Nguyên tắc Giải thích chi tiết
1 !important Các thuộc tính đi kèm từ khóa !important có mức ưu tiên cao nhất tuyệt đối.
2 Inline CSS Các định dạng đặt trực tiếp trong thuộc tính style="..." của thẻ HTML.
3 Media Type / Query Điều khiển hiển thị phụ thuộc vào kích thước màn hình thiết bị.
4 Trọng số CSS (Specificity) Điểm số tính dựa trên cấu trúc bộ chọn (ID, Class, Element).
5 Nguyên tắc thứ tự cuối (Rule order) Nếu cùng trọng số, định dạng khai báo ở dòng dưới/sau sẽ đè lên dòng trước.
6 Kế thừa CSS từ thẻ cha Nhận thông số từ phần tử chứa nó nếu không có định dạng riêng.
7 Mặc định trình duyệt Trình duyệt tự quy định nếu không có bất kì khai báo CSS nào.
🔢

Bảng giá trị đóng góp trọng số CSS

Quy tắc cộng điểm cho từng thành phần trong bộ chọn.

100

Mã định danh (ID)

Ví dụ: #home

10

Class, Lớp giả, Thuộc tính

Ví dụ: .test, :hover

1

Phần tử, Phần tử giả

Ví dụ: p, ::first-letter

0

Bộ chọn vạn năng

Ví dụ: *

Bộ chọn (Selector) Trọng số Giải thích thành phần
p > em 2 Gồm 2 phần tử thẻ (p và em): 1 + 1 = 2.
.test #p11 110 Gồm 1 class (10) và 1 id (#p11 = 100): 100 + 10 = 110.
p.test em.more 22 Gồm 2 phần tử (2 x 1 = 2) và 2 lớp (2 x 10 = 20): Tổng = 22.
p > em#p123 102 Gồm 2 phần tử (2) và 1 id (100): Tổng = 102.

Ví dụ thực tế: Cụm từ "Tin học 12"

Xét phần tử <p>Tin học 12</p> có 2 định dạng CSS áp dụng: Định dạng phía trên dùng Pseudo-class (trọng số 10), định dạng phía dưới dùng Element (trọng số 1). Kết quả: Định dạng trọng số lớn hơn (10) được chọn và chữ hiển thị màu xanh lá cây!
